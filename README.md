# JhunKeeper

A personal "don't drop a ball" board for staying on top of activities, due
dates, times, and recurring routines. React + Vite. No backend, no login —
tasks are saved in this browser on this device (localStorage). Installable as a
PWA (Progressive Web App) so it runs like a real app on your phone.

## What it does

- **Add activities** with an optional due date and optional time.
- **Recurrence** — Once / Daily / Weekly (pick weekdays). Missed recurring
  tasks roll forward instead of piling up as overdue.
- **Plain-language deadlines** — "Due today", "Due in 5 days", "3 days overdue".
- **Auto-overdue** — anything past due that isn't done turns coral on its own.
- **Per-task notes** — jot how it went, blockers, follow-ups.
- **Upcoming date dividers** — This week / Next week / Later this month / month
  names, so future work is easy to scan.
- **Done / To do / Overdue** instrument readouts at the top.

## Install on your phone (PWA)

Deploy to Vercel (below), open the live URL on your phone, then:

- **iPhone (Safari):** tap the Share button -> **Add to Home Screen**.
- **Android (Chrome):** tap the menu (three dots) -> **Install app** / **Add to
  Home screen**.

It gets its own icon, launches fullscreen with no browser bar, and works
offline. Note: data lives on each device separately — your phone's board and
your laptop's board are independent copies (syncing would require a backend).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build      # outputs to dist/ (includes manifest + service worker)
```

## Deploy to Vercel

Import the repo in Vercel. Framework preset **Vite**, build `npm run build`,
output dir `dist`. `vercel.json` handles SPA routing. Vercel serves over HTTPS,
which the PWA service worker requires.

## Regenerating icons

App icons live in `public/` and are generated by `make_icons.py`
(`python3 make_icons.py`). Edit that script to restyle the icon.

## Logic tests

Date/status/sort/recurrence/divider logic is isolated in `src/logic.js` and
covered by `test-logic.mjs`:

```bash
node test-logic.mjs
```
